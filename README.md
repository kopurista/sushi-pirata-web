# Sushi Pirata — build web

Publicación de la versión jugable en navegador de **Sushi Pirata**, servida con
GitHub Pages.

Esta carpeta contiene **archivos generados**, no código fuente: son el resultado
de exportar el proyecto de Godot 4.7.1 al destino Web. No se editan a mano; para
actualizarlos se reexporta desde el proyecto y se reemplaza el contenido.

El código del juego vive en [sushi-pirata](https://github.com/kopurista/sushi-pirata).

## Cómo jugar

Abre la página en el navegador. **En iPhone es importante añadirlo a la pantalla
de inicio** (Compartir → Añadir a pantalla de inicio): iOS borra el
almacenamiento de los sitios web a los 7 días, y solo se libra de ello lo que
está instalado como aplicación. Sin eso se pierde la partida guardada.
